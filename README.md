# 大肥鱼桌宠 · v0.1

Windows 原生透明桌宠。支持拖动、鼠标八方向视线跟随、自然眨眼、拎起与落地动画，以及大小和各类动画速度的独立调节。

## 直接运行

下载并解压整个项目，双击根目录的 **大肥鱼桌宠.exe**。需要 Windows 自带的 .NET Framework 4.x，不需要安装 Python、Node.js 或其他运行库。

- 按住鼠标左键拖动，播放拎起和落地动作。
- 角色根据鼠标相对位置平滑看向八个方向，鼠标静止 5 秒后回正。
- 每 3–5 秒自然眨眼，待机时有轻微呼吸。
- 右键可调节大小、置顶和七类动画的独立倍率；滑块与数值输入均可使用。
- 鼠标滚轮可快速缩放。位置、大小和倍率保存在本地 `data/settings.txt`，该文件不会上传到 Git。

## v0.1 特点

- 姿势过渡每一帧只使用一套完整角色绘画，解决头发、尾巴和脸部双轮廓。
- 八个方向都加入真实半程姿势，快速移动鼠标时仍能保持顺滑。
- 眨眼只替换眼睛区域，不影响头发、脸型、身体或透明轮廓。
- 正视与方向姿势使用同一套生成形象和色彩。
- 非激活窗口继续保持实时动画调度；进程优先级仍为 Normal。
- 右转呆毛保持原方向，上、左上、右上的抬头幅度经过调整。

## 从源码构建

在项目根目录打开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

默认生成根目录的 EXE。程序正在运行时可先退出，或指定另一个输出路径：

```powershell
.\build.ps1 -OutputPath .build\PetAnimated.exe
```

构建使用 Windows .NET Framework 4.x 自带的 C# 编译器。

## 验证

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\check.ps1
```

检查动画倍率、数值输入、八方向跟随、五秒回正、拖拽连续性、眨眼眼外像素不变、单源画面约束和缩放边界。v0.1 已通过 496 组原生 WPF 渲染检查，并由用户实机确认转头顺滑。离屏耗时不等于显示器实际帧率。
