# 动画渲染约定

## 一次只绘制一套人物线条

`PetMotionWarp.RenderWeighted` 的权重只描述目标几何位置，不再用于混合不同姿势的 RGB 或 alpha。每次输出选定一个源姿势，只从这一张图采样；其他姿势只提供位移参考。双帧的 `Render` 也走同一路径，不能另加整图淡入淡出作为回退。

位移采样会对同一源图的邻近像素进行双线性插值，这是抗锯齿采样，不是叠加两套人物。缺少位移数据时保持所选姿势，禁止自动退回两张整图叠加。

`PetSpriteView.DrawPose` 每次只调用一次人物 `DrawImage`。呼吸、晃动、点击和起落的整体变换作用于这张图。渲染缓存命中时直接使用该单帧；不可把上一帧的透明内容累积到下一帧。

眨眼仅在当前朝向的眼部遮罩内更新。眼部以外的图案和透明通道必须保持原姿势不变，不用闭眼素材替换整个头部。

## 新动作的接入

1. 准备人物比例、脚底基线、颜色和部件遮挡关系一致的关键帧或逐帧素材。
2. 让状态机输出动作进度及几何权重，通过现有单帧渲染入口播放。中断动作时从当前进度衔接，不同时启动两层人物动画。
3. 若跨度过大或头发分叉、尾巴、衣物遮挡发生拓扑变化，应补绘实际中间帧。位移补间不能创造缺失的线条和被遮挡的部件，禁止靠透明叠图掩盖缺帧。
4. 检查切换点、快速反向、拖拽中断、眨眼重合时刻，不能只看首尾静态姿势。

## 验证边界

`tests/KeyframeChecks.cs` 使用互斥纯色源图验证双帧和三帧过渡不会产生跨姿势混色，并检查单帧直通、动作中断连续性、眨眼遮罩、边界抖动及各类倍率。

这些检查能防止重新引入整图叠加，不能证明任意素材组合在换帧时都自然。关键帧间的外观跳变和素材本身的残影仍需逐帧检查与实际试用；需要时补绘帧，不能把程序检查通过当作美术连续性合格。
